This project was created as a test task. The main goal was to create an Android application with two specific screens:
1.  **Movie List:** A screen that displays a list of trending movies
2.  **Movie Details:** A screen that shows detailed information about a specific movie when the user clicks on it from the list

## Tech Stack
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose 
* **Architecture:** Clean Architecture + MVVM
* **Dependency Injection:** Hilt
* **API communication:** Retrofit + OkHttp
* **Image Loading:** Coil

## How to Run
1. Clone the repository
2. Open the project in Android Studio
3. Add your TMDB API Read Access Token to the local.properties:
```API_KEY=your_access_token```
4. Run on an emulator or Android device (Android 7.0+)
